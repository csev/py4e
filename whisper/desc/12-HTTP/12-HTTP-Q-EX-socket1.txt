Python Socket HTTP GET Request

python, socket, http, get, tcp, port, utf8, encoding

This lecture demonstrates a Python script that simulates an HTTP GET request using socket programming. The script connects to the web server data.pr4e.org on port 80 and retrieves the file romeo.txt by sending a minimal HTTP request.

The code creates a socket connection, sends the HTTP GET command followed by a newline and a blank line, and reads the response in 512-byte chunks until the connection closes. The response data is decoded from UTF-8 to Python's Unicode format.
