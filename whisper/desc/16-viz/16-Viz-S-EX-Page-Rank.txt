Running PageRank Algorithm on Spider Retrieved Pages

pagerank, sqlite, graph_theory, strongly_connected_component, python, page_rank_algorithm

This lecture demonstrates implementing the PageRank algorithm on a dataset of 107 web pages retrieved by a spider. The algorithm uses a SQLite database to store the links and compute page ranks iteratively. The implementation focuses on identifying the strongly connected component of the graph to efficiently process the links.

The PageRank calculation begins with all pages assigned a rank of one. In each iteration, the algorithm distributes the rank across outbound links with an evaporation factor to prevent trapping. The page ranks stabilize within 12 iterations, with the average difference between consecutive iterations becoming less than 0.005.
