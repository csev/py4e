Mailing List Activity and Word Cloud Visualization

database, normalization, visualization, wordcloud, activity, mailinglist

This lecture demonstrates a mailing list data crawling application that retrieves from mvoxdrchuck.net, a cached copy of gmain.org, to avoid rate limiting and server crashes. The data spans from 2004 to 2013 and is over a gigabyte in size, with issues including changing email addresses and inconsistent date formats.

The application processes raw data into a normalized SQLite database (index.sqlite) with foreign keys. Two visualizations are generated: an activity line graph using gline and a word cloud using gword, both implemented with d3.js. The cleanup process to rebuild the normalized database takes between 2 and 10 minutes.
