Web Crawler and PageRank Implementation with SQLite

crawler, pagerank, sqlite, robots, d3js, index, visualization

This lecture demonstrates a web crawler that uses SQLite to store retrieved web pages and links. The crawler starts with one URL, retrieves pages, parses HTML to extract links, and adds new URLs to a queue for future retrieval. It respects robots.txt to avoid prohibited content and can be restarted without losing progress.

The PageRank algorithm computes page importance by iteratively updating scores starting at 1.0 for all pages. After convergence, the scores stabilize with minimal average change. The system visualizes PageRank results using d3.js in a force-directed layout for interactive exploration.
