Personal Data Mining: Web Data Retrieval and Visualization

databases, webservices, ratelimited, datacleaning, geocoding

This lecture describes a personal data mining pattern for small to medium-sized datasets. It involves retrieving data from the internet using web services, storing raw data in a database, and then cleaning and processing it to create a clean dataset for visualization or analysis.

The process is designed to handle rate limits by running slowly and restartably, which can take several days for large datasets. Raw data is stored in a database to track progress and avoid reprocessing, and if the data is not clean, an additional cleaning step is performed.
