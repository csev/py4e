Python Gmail Data Analysis: Word Cloud and Line Chart Examples

python, sqlite, d3js, wordcloud, linechart, visualization

This lecture demonstrates basic Python analysis techniques on a cleaned Gmail dataset. The course uses a 260 megabyte SQLite database containing 59,000 messages and 29,000 subjects.

The examples include counting top senders and organizations, generating word clouds, and creating line charts for time-series data. The scripts process subject lines to count words after normalization and produce visualizations using D3.js.
