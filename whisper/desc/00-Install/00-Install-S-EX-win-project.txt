Install Python 3 on Windows and Write First Program

python, windows, commandline, texteditor, installation

This lecture details the installation of Python 3 on Windows and the selection of a programmer text editor. The instructor specifies that the text editor must be a dedicated programming editor (not Word or TextEdit) and provides examples including Atom, Notepad++, and J-Edit.

The lecture demonstrates running the Python interpreter via the Windows command prompt, creating a directory named PY4E on the desktop, and writing a simple "hello world" program in a file called first.py. It also explains the Windows file association for .py files and how to execute the program from the command line.
