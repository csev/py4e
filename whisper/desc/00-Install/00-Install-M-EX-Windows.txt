Python 3.14 Installation on Windows with Hello World

python, windows, installation, terminal, hello_world, text_editor

This lecture covers installing Python 3.14 on Windows by downloading the installer from python.org and running the setup. It verifies the installation by opening the terminal and executing a basic Python command.

The lecture then creates a "hello world" script using the text editor Thani, saves it to the desktop, and runs it via Thani or the terminal. It also demonstrates navigating the Windows file system using command-line commands to run scripts from specific directories.
