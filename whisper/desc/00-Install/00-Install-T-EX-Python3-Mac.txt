Install Python 3 on macOS

macos, python3, terminal, hello_world

This lecture details installing Python 3.6 from python.org on macOS. The user creates a "Hello, world" program using the Adam editor and verifies the installation in the terminal.

The program runs successfully with the python3 command. The lecture notes that the same program would produce a syntax error when run with Python 2 due to differences in the print statement.
