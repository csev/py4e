Python 3.14 Installation on macOS for Python for Everybody

macos, python, terminal, thonny

This lecture walks through installing Python 3.14 on macOS for the Python for Everybody course. It checks pre-installed Python versions in the terminal, installs Python 3.14 (newer than the default Python 3.9), and configures SSL certificates. The instructor then installs Thonny, a free and open-source Python IDE with a built-in interpreter.

The tutorial creates a "Hello World" program in Thonny, saves it as first.py, and demonstrates running it via Thonny and the terminal. It explains terminal commands for checking Python versions and executing scripts.
