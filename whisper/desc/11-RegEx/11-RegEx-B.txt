Regular Expression Findall Method: Greedy vs Non-Greedy Matching and Capturing Groups

regex, findall, greedy, nongreedy, capturing

The lecture explains the findall method in regular expressions, which returns a list of all matching strings. Unlike the search method that returns a boolean, findall provides a list of strings that match the pattern. Examples include matching one or more digits [0-9]+ and one or more uppercase vowels [AEIOU]+, where the latter returns an empty list in certain contexts.

The lecture details greedy and non-greedy matching behavior. By default, regex engines use greedy matching, which selects the longest possible substring when multiple matches are possible. Non-greedy matching (denoted by ? after quantifiers) selects the shortest substring. Parentheses are used to create capturing groups for extracting specific parts of the match, as illustrated in examples involving email addresses.
