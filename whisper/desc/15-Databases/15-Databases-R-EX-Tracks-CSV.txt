Python CSV to SQLite Database Normalization Example

csv, sqlite, database, normalization, foreignkey, primarykey

This lecture demonstrates a Python script that processes a comma-separated values (CSV) file named tracks.csv and populates a SQLite database. The database follows normalization principles to ensure each artist appears only once with a primary key, while foreign keys link artists to albums and albums to tracks.

The script skips CSV lines with fewer than six fields and inserts records in sequence: artists, then albums using artist ID as foreign key, then tracks using album ID as foreign key. It drops and recreates database tables before each execution to maintain a clean state.
